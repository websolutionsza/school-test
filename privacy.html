Overview

This privacy policy describes how the Greenwood High School website (the "website") handles information when you visit. The website is operated on behalf of Greenwood High School by WebSolutionsSA.

This is a prototype website. Where official school privacy wording is required, the school administration should provide the official text to replace this page.

Information We Collect

The public pages of this website do not require you to provide personal information. Specifically:

  • We do not run analytics or advertising trackers on the public pages of this prototype.
  • We do not ask learners or parents to create accounts on the public website.
  • Map embedding on the Contact page loads content from Google Maps; Google may collect information about your visit to that page independently of this website.

The administration portal is a separate, restricted area. Only authorised school staff have accounts. Authentication is handled by the school's backend service (PostBase). Sign-in activity is governed by that service's own policies.

How We Use Information

Information collected by the website is used only to display public content (announcements, posts, contact details) and to operate the administration portal. We do not sell or rent information to third parties.

Cookies & Local Storage

This website uses your browser's local storage for the following functional purposes only:

  • Theme preference — remembers whether you selected light or dark mode.
  • Recently viewed pages — a short list of public pages you have visited, shown to you on the homepage. This never includes admin pages.
  • Runtime configuration cache — caches the public PostBase configuration for a few minutes so it does not need to be re-fetched on every page navigation.
  • Admin drafts — if an administrator is editing a post or announcement and leaves the form unfinished, the unfinished text is stored locally so it can be recovered. This is only on the device being used.

The administration portal also uses a per-tab session flag so that signing out is enforced when the tab is closed. This is not persistent across browser sessions.

Third-Party Services

The website uses the following third-party services:

  • PostBase — backend database and authentication for the admin portal.
  • PostFile — file storage for media attached to announcements and posts. File uploads are sent through this website's own server (/api/upload) so that the upload service's API key is never exposed in the browser.
  • Google Maps — embedded map on the Contact page.
  • Google Fonts — web fonts loaded from fonts.googleapis.com.
  • jsDelivr CDN — used to load the PostBase JavaScript SDK.

Each of these services operates under its own privacy policy.

Your Choices

You can clear local storage at any time through your browser's settings. Clearing local storage will:

  • Reset the theme to your operating system preference.
  • Clear the recently-viewed list.
  • Discard any unsaved draft text from the admin forms.

If you do not want Google Maps to load, do not visit the Contact page, or use a content blocker to prevent third-party iframes.

Contact

If you have questions about this privacy policy or how the website handles information, please contact the school office using the details on the Contact page.
